MCP-Server · öffentlich · nur lesend

wpir-mcp

MCP-Server (Model Context Protocol) mit Förderprogrammen und gesetzlichen Regelungen rund um den Umstieg von Gas oder Öl auf eine Wärmepumpe.

Der Server dient dem Wärmepumpen-Investitionsrechner als Wissensbasis, gegen die seine Standardwerte auf Aktualität geprüft werden.

Hinweise

  • Jeder Fakt trägt Quelle, Prüfdatum und Status (bestätigt, Sekundärquelle oder Annahme).
  • Maßgeblich sind die Originalquellen, die jeder Fakt angibt. Die Angaben sind keine Rechts- oder Förderberatung.
  • Der Server ist öffentlich und nur lesend: keine Anmeldung, kein Schreibzugriff.
  • Keine Nutzerdaten: Der Server verarbeitet nur die gesendeten Feldpfade und Werte und speichert oder protokolliert sie nicht.

Anbindung

Adresse des MCP-Endpunkts: https://mcp.wpir.de/mcp

Verbinden Sie den Server mit Claude Code über diesen Befehl:

claude mcp add --transport http wpir-mcp https://mcp.wpir.de/mcp

Der Endpunkt nimmt nur POST entgegen (Streamable HTTP); andere Methoden werden mit 405 abgewiesen.

Beispielaufruf für check_value mit dem Feldpfad funding.grundRate und dem Wert 0.25:

{ "name": "check_value", "arguments": { "key": "funding.grundRate", "value": 0.25 } }

Werkzeuge

Alle Werkzeuge sind nur lesend.

list_topics
Listet die Themen mit der Anzahl ihrer Fakten und dem ältesten Prüfdatum.
get_facts
Liefert Fakten nach Thema, ID, Freitext oder Feldpfad des Rechners, mit Regel, Referenzwerten, Gültigkeit, Status, Prüfdatum und Quellen.
list_sources
Liefert jede Quelle einmal, mit den Fakten, die sie belegen.
list_keys
Liefert die Feldpfade des Rechners, für die es einen Referenzwert gibt.
check_value
Vergleicht einen Wert des Rechners mit dem Referenzwert und meldet gleich, abweichend oder unbekannt, mit Quelle.
